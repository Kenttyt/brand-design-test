Guidelines

Rules for consistent and correct use of the Baldo brand across all touchpoints.

Logo Usage
✓ Do
✓
Use approved color combinations
Always use the logo in one of the three approved combinations: dark on light, light on dark, or gold variant.
✓
Maintain clear space
The minimum clear space around the logo is equal to the height of the letter 'B'.
✓
Use the correct lockup for the medium
Use the full logo on desktop, abbreviated form on tablet, and monogram on mobile.
✗ Don't
✗
Don't stretch or distort
Never scale the logo non-proportionally or apply skew/perspective transforms.
✗
Don't use unapproved colors
Only use the three brand-approved color combinations. Never place the logo on busy backgrounds.
✗
Don't add effects
Avoid shadows, gradients, outlines, or any visual effects applied directly to the logo mark.
Typography Rules
T
Playfair Display is exclusively for headlines
Use Playfair Display only for H1, H2, H3 headings, the logo wordmark, and decorative display text. Never use it for body copy or UI labels.
P
Poppins is the body and UI typeface
All body text, captions, labels, navigation, and interface copy should be set in Poppins at the correct weight (Light 300, Regular 400, Medium 500, SemiBold 600).
↕
Respect the type scale
Always use the defined type scale. Do not introduce new sizes outside the scale. Maintain appropriate line-height ratios for readability.
A
Letter-spacing for caps
All-caps text must have a minimum letter-spacing of 2.5px. This applies to taglines, labels, and section headers set in uppercase.
Color Guidelines
🎨
Gold as an accent, not a primary background
Gold (#C9A961) should be used sparingly as an accent — dividers, monogram fills, CTAs. Avoid using gold as a dominant background color in large interfaces.
◑
Minimum contrast ratio 4.5:1
All text must meet WCAG AA accessibility standards. Dark text on light backgrounds and light text on dark backgrounds must achieve a 4.5:1 contrast ratio minimum.
🚫
No unapproved colors
Do not introduce colors outside the brand palette without approval. The palette is intentionally limited to maintain brand coherence and luxury positioning.
